# Software Sarathi

Responsive marketing website for softwaresarathi.com. Open index.html in a browser to preview; no build or dependencies required. Fonts load from Google Fonts with local fallbacks.

## Cloudflare Pages

Connect this repository, choose the software-sarathi branch, set the root directory to software-sarathi, leave the build command empty, and use . as the output directory. Add softwaresarathi.com as a custom domain after deployment. If this branch is merged, choose main instead.

## Enquiries

The project brief form downloads a text file on the visitor's device. It does not send enquiries or save customer data to a server. Configure an agreed business email, WhatsApp number, or form endpoint before using this page to collect leads.

## Validation

The page returned HTTP 200 locally and its inline JavaScript passed Node syntax validation. Browser visual and interaction verification has not been completed.
